# Formatting engine templates

Two kinds of templates live in this directory:

1. **CSL stylesheets** under `citation-styles/`. These tell Pandoc's
   citeproc filter how to format in-text citations and bibliography
   entries per a given style.
2. **Reference DOCX files** at the top level. These tell Pandoc the
   default fonts, margins, line spacing, and heading styles to use
   when emitting a `.docx` output.

Both are vendored in-repo per Rule 28 (no runtime fetch from a
third-party host). Both are regenerated by hand only when the
underlying style changes — which is once every 5–10 years per style.

## CSL stylesheets

Source: https://github.com/citation-style-language/styles
License: CC BY-SA 3.0 (in-tree-friendly)

Required files (commit to `citation-styles/`):

| Style key (frontend / API) | Source file in CSL repo | Local filename |
|---|---|---|
| `mla` | `modern-language-association.csl` | `mla.csl` |
| `apa` | `apa.csl` | `apa.csl` |
| `chicago-author-date` | `chicago-author-date.csl` | `chicago-author-date.csl` |
| `chicago-note` | `chicago-note-bibliography.csl` | `chicago-note.csl` |
| `ieee` | `ieee.csl` | `ieee.csl` |
| `harvard` | `harvard-cite-them-right.csl` | `harvard.csl` |

To refresh (run once when a style major-version updates):

```bash
cd backend/src/services/formatting/templates/citation-styles
for f in \
  modern-language-association.csl \
  apa.csl \
  chicago-author-date.csl \
  chicago-note-bibliography.csl \
  ieee.csl \
  harvard-cite-them-right.csl
do
  curl -sSL "https://raw.githubusercontent.com/citation-style-language/styles/master/$f" \
    -o "$(basename "$f" .csl | sed 's/modern-language-association/mla/;s/chicago-note-bibliography/chicago-note/;s/harvard-cite-them-right/harvard/').csl"
done
git add citation-styles/*.csl
git commit -m "Refresh CSL stylesheets from upstream"
```

Verify each file starts with `<?xml version="1.0" encoding="utf-8"?>`
and contains `<style xmlns="http://purl.org/net/xbiblio/csl"`.

## Reference DOCX files

These are binary `.docx` files. Pandoc uses them as a starting
template — every paragraph, heading, and reference list inherits its
visual style from this template. Hand-edited once per style guide,
committed to the repo, refreshed only when a style guide changes its
typography (rare).

Required files (commit to this directory):

| Style key | Local filename |
|---|---|
| `mla` | `mla-reference.docx` |
| `apa` | `apa-reference.docx` |
| `chicago-author-date` | `chicago-reference.docx` (same file for both Chicago variants) |
| `chicago-note` | `chicago-reference.docx` |
| `ieee` | `ieee-reference.docx` |
| `harvard` | `harvard-reference.docx` |

### Generation procedure (one-time per style)

1. Print the Pandoc default reference template to a working file:

   ```bash
   pandoc --print-default-data-file=reference.docx > /tmp/ref-mla.docx
   ```

2. Open the file in Microsoft Word or LibreOffice Writer.

3. Apply the style guide's typography rules:

   **MLA (9th ed.):**
   - Font: Times New Roman 12pt throughout
   - Margins: 1 inch on all sides
   - Line spacing: 2.0 (double)
   - First-line indent on body paragraphs: 0.5 inch
   - Headings: same font/size as body, bold; no special heading styling
   - Works Cited: hanging indent 0.5 inch on entries

   **APA (7th ed.):**
   - Font: Times New Roman 12pt OR Calibri 11pt OR Arial 11pt
     (pick one; commit to it)
   - Margins: 1 inch on all sides
   - Line spacing: 2.0 (double)
   - Body paragraphs: 0.5 inch first-line indent
   - Headings: Heading 1 = bold + centered + Title Case; Heading 2 =
     bold + flush left + Title Case
   - References: hanging indent 0.5 inch

   **Chicago (Author-Date AND Notes-Bibliography):**
   - Font: Times New Roman 12pt
   - Margins: 1 inch on all sides
   - Line spacing: 2.0 (double) for body; 1.0 (single) within
     individual footnotes/bibliography entries with a blank line
     between entries
   - Body paragraphs: 0.5 inch first-line indent
   - Notes (Notes-Bibliography variant): superscript references, full
     citations on first use, short-form thereafter

   **IEEE:**
   - Font: Times New Roman 10pt (note the smaller size)
   - Margins: 0.75 inch top/bottom, 0.625 inch left/right (two-column
     journal-style — OK to use single-column for our reports)
   - Line spacing: 1.0 (single)
   - Headings: bold, all caps for Heading 1; bold Title Case for
     Heading 2
   - References: bracketed numeric `[1]` `[2]`...; flush left, no
     hanging indent

   **Harvard (Cite Them Right variant):**
   - Font: Times New Roman 12pt or Arial 11pt
   - Margins: 1 inch
   - Line spacing: 1.5 or 2.0 (institutional preference; default 2.0)
   - References: hanging indent 0.5 inch

4. Save the edited file with the canonical filename
   (`mla-reference.docx`, etc.) in this directory.

5. Commit. The file is small (~30KB).

### Verification

Each reference template should:

- Open cleanly in Microsoft Word, LibreOffice Writer, and Apple Pages.
- Render through Pandoc without warnings:
  ```bash
  echo "# Test\n\nBody text." | \
    pandoc -f markdown -t docx \
      --reference-doc=apa-reference.docx \
      -o /tmp/smoke.docx
  ```
- Visibly match the style guide when a sample report is exported
  using it. Compare against a few published papers in the same style
  to spot-check margins and line spacing.

## When to refresh

- **CSL files**: when a style organization (APA, MLA, etc.) releases
  a new edition. Refresh frequency: ~once per 5 years per style.
  The upstream CSL repo tracks edition updates within ~6 months.
- **Reference DOCX files**: when a style guide changes its
  typography rules. Refresh frequency: ~once per 5–10 years per
  style. Or when the operations team notices a customer-facing
  complaint about font/margin compliance.

Document each refresh in `CHANGELOG.md` (or this README's footer)
with date and reason.
